## 🌟 Key Engineering Highlights
- 📊 **Tableau Hyper API Integration:** Replaces traditional slow CSV exports by programmatically compiling massive Pandas DataFrames into hyper-optimized `.hyper` extract files.
- 🛍️ **Consumer Behavior Analytics:** Exploratory Data Analysis (EDA) decoding seasonal retail trends, basket analysis, and category-level velocity.
- 📈 **Visualization Engine:** Deep visualization layer utilizing `Seaborn` and `Matplotlib` to isolate outlier transactions and macro revenue trends.
- 🧹 **Robust Data Cleansing:** Imputation of missing inventory records and normalization of time-series sales indices.

## 🛠️ Technology Stack
* **Data Engineering:** `Tableau Hyper API`, `Pandas`
* **Analytics & EDA:** `NumPy`, `SciPy`
* **Visualization:** `Matplotlib`, `Seaborn`
* **BI Platform:** `Tableau`

## 📊 The `.hyper` Advantage
By leveraging the **Tableau Hyper API**, this pipeline bypasses standard delimited formats, resulting in:
- **10x Faster Dashboard Rendering:** Optimized columnar storage reads.
- **Strict Typing:** Programmatically enforced database schema mapping.
- **Enterprise Scale:** Ability to seamlessly append millions of rows to the extract artifact without memory overflow.
